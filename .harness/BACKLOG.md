# BACKLOG.md — 기술 부채 및 추후 개선 아이디어

## 1. 지능형 기능 고도화 아이디어
- [ ] **멀티모달 책 표지 감성 분석**: 사용자가 찍은 책 표지 사진에서 색감/분위기를 추출하여 페르소나의 오프닝 멘트에 반영.
- [ ] **다자간 토론(Multi-Persona Debate) 오케스트레이션**: 사용자의 질문에 대해 평론가(이동진 톤)와 이야기꾼(설민석 톤)이 서로 다른 관점으로 티키타카를 나누는 듀얼 페르소나 모드.
- [ ] **음성 TTS 연동**: 사서 페르소나별 보이스 프로필을 생성하여 Web Speech API 또는 무료 TTS 연동.
